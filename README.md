# Calculator (Python)

A simple calculator that performs basic arithmetic operations based on user input.

## Features
- Addition, subtraction, multiplication and division
- Takes numbers and the operation from the user

## Tech used
- Python 3
- Jupyter Notebook

## How to run
Requires Python 3.8 or newer.

    python CalculatoR.py

Or in Jupyter Notebook, run the notebook cells in order.

## What I practiced
- Python input and output
- Conditionals and functions
- Working with Jupyter Notebook and GitHub
